# Channel Profiles — the Form Contracts

> **Last restamped: 2026-07-24** *(event-driven — restamped when a platform's conventions visibly change or an owner policy overrides them, never on a clock; this move was the second kind, the no-emoji default, not a platform shift)*. This file is commwright's one volatile surface, declared in `metadata.volatile`; ask for a channel-profile update in an ordinary request when a platform's norms move.

Load the target channel's section on every draft. Four fields per profile: **register** (tone), **length contract** (ceiling, not target), **structure**, **subject/title rules**.

**Register layer.** Every profile below sits under the humanize hard rules **H1 to H9**, which live in the SKILL body and bind across all channels: no em or en dashes in any role, no emoji, no scaffolding, no inflated constructions, an actor in every sentence. They arrive with the body, so this one profile section is still the only file a draft opens. No profile suspends them. Where the two meet, the profile's length contract and required structure win and H1 to H9 decide the rest. On emoji there is nothing to reconcile: every profile below defaults to none, and the only relief is the H2 per-message override. The deep tell catalog in `references/humanize.md` is not a per-draft load.

## Email

**Formal** (institutions, strangers, disputes): register — courteous, complete sentences, zero slang; length — ≤200 words body; structure — greeting · one-line purpose · detail paragraph · explicit ask · sign-off; subject — 4–8 words, noun-led, no "quick question".
**Family**: register — warm, contractions fine, plain; length — ≤120 words; structure — lead with the point, detail only if asked-for; subject — plain words, or none if replying.
**Work** (colleagues, known contacts): register — direct professional, first names; length — ≤150 words; structure — purpose in line 1 · context · ask with a date; subject — verb-led, decision-relevant ("Approve Q3 deck by Fri").

## Text / SMS

Register — casual-direct, matches the relationship; the thread's own norm may be full of emoji, and the draft still carries none unless asked for on that message; length — ≤2 message bubbles, ≤300 chars total; structure — point first, logistics second, one question max; no subject. Never multi-topic.

## Teams / Slack

Register — professional-casual; no emoji, and the channel norm here is emoji-rich, so that is a deliberate departure a human can reverse for one message by asking; length — ≤120 words or 5 bullet lines; structure — bold lead line · bullets for parallel facts · thread for detail; @mentions only for owners/deadlines, never @channel unless truly all-hands; no subject — the lead line is the subject.

## GitHub release notes

Register — factual, changelog-plain, second person for actions users take; length — ≤40 words per item; structure — Keep-a-Changelog buckets (Added / Changed / Fixed / etc.), breaking changes first and marked, upgrade note last; title — `vX.Y.Z: <3 to 6 word theme>` (the template itself obeys H1; a dash here would mandate the character the rule forbids).

## YouTube

**Title:** ≤60 chars, front-load the payoff keyword, no clickbait promises the video can't cash. **Description:** first 2 lines carry the hook + core keywords (they show before the fold); then chapters/timestamps; then links; then boilerplate. Register — energetic but literal to the content; no emoji in the title or the description, even though competing titles and thumbnails use them freely, unless asked for on that upload.

## Social posts

Register — one idea per post, native to the platform's cadence; length — X/short-form ≤240 chars, LinkedIn ≤120 words; structure — hook line · substance · one CTA max; hashtags ≤3 and only load-bearing ones; no emoji, whatever the feed's norm is, unless asked for on that post; no subject.

## Discord announcements

Register — community-warm, direct; server culture runs on emoji and reactions, and the announcement still ships with none unless asked for on that message; length — ≤150 words; structure — `**bold headline**` · what changed / what's happening · what members should do · one link block; ping the narrowest role that covers the audience, @everyone only for genuinely-everyone news.
